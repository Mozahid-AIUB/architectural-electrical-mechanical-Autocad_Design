# Architectural, Electrical & Mechanical AutoCAD Design

A collection of AutoCAD design projects covering architectural, electrical, and mechanical disciplines.

## Overview
This repository showcases various AutoCAD design projects including building layouts, electrical schematics, and mechanical drawings.

## Project Categories
- **Architectural**: Building designs, floor plans, elevations
- **Electrical**: Circuit designs, wiring diagrams, panel layouts
- **Mechanical**: Equipment designs, assembly drawings, technical specifications

## Tools Used
- AutoCAD
- CAD design software

## How to Use
1. Download the `.dwg` files from the repository
2. Open them in AutoCAD or compatible software
3. Review and modify as needed
